# Ascend 搜索空间与跨方向权衡

训练配置的可行域是模型语义、整数约束、实现支持、拓扑与显存容量的交集。显存、计算和通信是评价方向，不是互斥的参数分组；同一调整通常同时改变多项成本。

## 三个方向如何相互影响

| 机制 | 可能收益 | 交换的代价 |
| --- | --- | --- |
| 增大 micro-batch | 改善矩阵粒度、摊薄调用开销 | 激活增大，固定 GBS 下 microbatch 数减少，可能加重 PP 空泡 |
| 重计算 / 卸载 | 减少 NPU 保存量 | 增加重放或搬运；省出的显存又可能容纳更高效的配置 |
| 模型或 optimizer 状态分片 | 降低单 rank 状态量 | 引入通信、局部计算粒度和恢复格式的变化 |
| 通信重叠与预取 | 缩短关键路径等待 | buffer 存活更久，并发任务可能争用带宽或计算资源 |
| 融合 / 图执行 | 减少中间量搬运或重复下发 | 资源活跃量、准备成本及动态输入限制可能抵消收益 |

可比较配置可能形成多个显存/速度折中点，而非一个在所有指标上都占优的解。单项变慢不排除组合获益，单项加速也不能相加为组合加速比；瓶颈可随配置改变。

## 搜索方法与证据的价值

小型离散空间适合枚举与约束剪枝；已有可行配置附近适合邻域搜索，但可能漏掉其他布局或跨方向组合。随机、贝叶斯等方法的价值取决于空间规模、测量噪声和样本预算，没有固定的 MBS、重计算、并行探索顺序。

候选价值同时取决于潜在收益、证据可信度、区分假设的信息量和实验成本。成本包括初始化、编译、预热、有效测量、退出与复测，而非仅训练步时。更大预算允许检查替代方向和联合配置，但不保证更大的空间必然产生更优结果。

固定布局且其他条件相同时，若显存随 MBS 近似单调，倍增与区间收缩可以估计容量边界。MoE token 偏斜、workspace、通信或图缓存可能破坏单调性；其他布局的 OOM 边界不能直接沿用。未经目标 NPU 校准的内存估计只适合作为排序线索。

性能退化、配置未生效、能力未知和外部运行失败是不同证据。一次失败只约束已测试的条件范围；没有新信息的重复不会扩大结论。“最佳”只相对于已完成且可比较的配置，不代表全局最优。

## 可比性的边界

精度、optimizer/LR/GBS、模型层数、序列长度、数据及 routing/token dropping 的变化可能改变训练语义或工作负载。此类结果不能直接计为原任务同条件下的实现加速。容量、吞吐和可靠性也有不同验收目标；短跑可行、模型更新等价与完整续训恢复不是同一结论。
